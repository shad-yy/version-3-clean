# Smart Live TV Store Archive

This folder contains all IPTV, subscription, channel reselling, pricing, setup guides, and store-related code and components preserved from the main `smart-live-tv` project.

Use these files when building the dedicated sales domain: `smartlivetv-store.com`.

## Directory Map

- `pages/` - Moved route pages (`/iptv-vs-sky-sports`, `/channels`, `/pricing`, `/setup`, `/buy`, `/free-trial`, `/subscribe`)
- `components/` - Store-specific React components (`channel-library`, `BuyForm`, `TrialForm`, `FirestickWizard`, `PricingCardsSlider`, `faq-accordion`, `why-iptv`, `pricing-preview`)
- `ui/` - Payment logos, device icons, speed checker widget
